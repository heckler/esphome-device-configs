# Fridge Sensors Mark II

New version of the ESPHome fridge monitor

CAH 2026-11-15

## Toner transfer PCB method

- To create the PDFs for each layer, use File > Print from the PDB editor
- Set the scale to 1:1 and print each side individually
- Print the back side (B.cu) without mirroring
- Print the front side (F.cu) mirrored
- If the board is small, join both PDFs in a single sheet with `merge_pages.py`
